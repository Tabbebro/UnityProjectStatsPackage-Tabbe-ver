Shows current and total statistics of Unity project. 
Works in Unity 6.3 and should work fine in earlier versions as well.

To install to your Unity project
1. Window -> Package Manager
2. Click "+" button on top left
3. Choose "Install package from git URL..."
4. paste "https://github.com/Tabbebro/UnityProjectStatsPackage-Tabbe-ver.git" to the field and click Install
